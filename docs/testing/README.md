# Testing 文件導覽

測試工作先讀整體策略，再依測試類型讀取實作規範：

1. [`testing-strategy.md`](testing-strategy.md)：測試分層、風險選擇、Coverage 與 Unit／API／E2E 分工。
2. [`backend-unit-testing.md`](backend-unit-testing.md)：Jest ESM、Mock、hook、fixture、命名與目錄。
3. [`frontend-unit-testing.md`](frontend-unit-testing.md)：Frontend 工具鏈建立前的限制與元件測試原則。
4. [`api-testing.md`](api-testing.md)：Postman、Data-Driven API Test 與 HTTP／DB 驗證方式。

實際執行命令以各 package 的 `package.json` 為準；API 測試資產的目前檔名與操作方式見 [`API-Tests/README.md`](../../API-Tests/README.md)。
