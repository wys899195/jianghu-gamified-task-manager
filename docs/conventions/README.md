# Conventions 文件導覽

`conventions/` 保存 Agent 在後續設計、實作與檢閱時必須遵循的 repository 與程式碼規範；亦供開發者查閱。

- [`project-structure.md`](project-structure.md)：Repository 目錄、Backend module 分層與檔案放置。
- [`coding-style.md`](coding-style.md)：檔案命名、TypeScript 型別與共通程式碼規則。
- [`comments/typescript.md`](comments/typescript.md)：TypeScript／TSX 註解格式與使用時機。

測試專屬命名、fixture、Mock 與註解由 `docs/testing/` 負責，不在此重複。
